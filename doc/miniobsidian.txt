1. INTRODUCTION                                      *miniobsidian-introduction*

miniobsidian.nvim provides Vault discovery and switching, note creation and search,
Wikilinks, templates, Daily Notes, checkboxes, and macOS image paste. It is a
standalone editor plugin with no external CLI or Agent integration.

The plugin does not coordinate concurrent writes from other applications. Neovim's
native file-change behavior applies. Plugin targets are restricted to the active
Vault, and notes, templates, Daily Notes, and images use no-replace publication.

===============================================================================
2. REQUIREMENTS AND INSTALLATION                    *miniobsidian-installation*

Required: Neovim >= 0.10.4.

Optional:

  snacks.nvim    quick switch and full-text search
  blink.cmp      Wikilink and checkbox completion
  ripgrep        full-text search
  osascript      macOS image paste

Vault and template selection fall back to vim.ui.select. Without snacks.nvim,
only ObsidianSwitch, ObsidianSearch, and ObsidianBacklinks are unavailable. Without
ripgrep, only full-text search is unavailable.

lazy.nvim plugin specification:
>lua
  {
    "andy-neoaira/miniobsidian.nvim",
    ft = "markdown",
    cmd = {
      "ObsidianNew", "ObsidianNewHere", "ObsidianSwitchVault",
      "ObsidianSwitch", "ObsidianSearch", "ObsidianBacklinks",
      "ObsidianMove", "ObsidianRename",
      "ObsidianTemplate",
      "ObsidianNewTemplate", "ObsidianPasteFile", "ObsidianToday",
      "ObsidianSetup",
    },
    config = function()
      require("miniobsidian").setup()
    end,
  }
<

Minimal setup:
>lua
  require("miniobsidian").setup()
<

Zero-config setup reads Obsidian's official obsidian.json, ignoring missing
entries and paths without .obsidian/. Manual discovery scans only direct
children of vaults_parent that contain .obsidian/:
>lua
  require("miniobsidian").setup({
    vaults_parent = "~/Documents/Obsidian",
    default_vault = "Personal",
    auto_discover = false,
  })
<

===============================================================================
3. CONFIGURATION                                           *miniobsidian-config*

Defaults and meaning:

  vaults_parent = ""
      Parent directory containing Vaults. Expands ~ and environment variables.

  default_vault = ""
      Initial Vault name. Missing names fall back to the first result. During
      automatic discovery, an Obsidian-marked open Vault is prioritized.

  auto_discover = true
      Read official Obsidian configuration when vaults_parent is empty.

  sync_obsidian_config = true
      Read settings from the active Vault. The plugin never writes .obsidian.

  notes_subdir = "Notes"
      Vault-relative new-note folder. Empty means the Vault root.

  dailies_folder = ""
      Vault-relative Daily Note folder.

  daily_template = ""
      Vault-relative Daily template Note ID. The .md suffix is optional.

  daily_default_content = ""
      Content for a new Daily Note when no template is configured.

  templates_folder = "Templates"
      Vault-relative template folder.

  attachments_folder = "Assets"
      Vault-relative image folder.

  daily_date_format = "%Y-%m-%d"
      Lua os.date format for Daily filenames and note frontmatter dates.

  picker_scope = "notes"
      "notes" searches notes_subdir; "vault" searches the complete Vault.

  change_cwd_on_switch = false
      Apply tab-local :tcd after a successful Vault switch.

  checkbox_states = { " ", "x" }
      Checkbox cycle and completion order.

  note_id_func = <built-in CJK slug function>
      Convert a title to a filename without .md. The default keeps ASCII
      alphanumerics and CJK text, removes other punctuation, changes consecutive
      whitespace to -, and lowercases ASCII.

  on_vault_switch = nil
      function(name, path), called after a successful Vault switch.

  after_note_open = nil
      function(path, opts), called after a direct plugin note open.

vault_path is internal runtime state and must not be configured manually.

Directory options reject parent traversal, absolute paths, hidden segments,
NUL, Windows ADS and device names, and segments ending in a dot or space.
daily_template receives the same Vault-boundary check when a Daily Note is
resolved.

Synchronized configuration:

  .obsidian/app.json
      newFileLocation="root" -> notes_subdir=""
      newFileLocation="folder" plus newFileFolderPath -> notes_subdir
      attachmentFolderPath (non-empty, not ".") -> attachments_folder

  .obsidian/daily-notes.json
      folder   -> dailies_folder
      supported Moment format -> Lua daily_date_format
      template -> daily_template

Precedence is explicit user configuration, active-Vault Obsidian settings, then
plugin defaults. Synchronized fields are rebuilt on every switch. Directory
fields validate before a runtime switch is committed; unsafe directories leave
the previous Vault active. Unsupported Moment tokens are not synchronized. A
missing, ambiguous, or unsafe daily_template aborts Daily Note creation later.

setup(opts) returns true on success. Invalid configuration, no valid Vault, or a
synchronized directory that fails validation returns false, errors and does not
fire MiniObsidianSetup.
Calling setup() again resets runtime configuration and caches before discovery;
unlike a runtime ObsidianSwitchVault, failure need not preserve the old state.

blink.cmp provider:
>lua
  opts.sources.providers.miniobsidian = {
    name = "MiniObsidian",
    module = "miniobsidian.completion",
    score_offset = 50,
  }
  table.insert(opts.sources.default, "miniobsidian")
<

4. COMMANDS                                              *miniobsidian-commands*

                                                               *:ObsidianNew*
:ObsidianNew[!] [title]
    Create or open a note in notes_subdir. A missing title opens an input prompt.
    ! passes opts.switch_root=true to after_note_open.

                                                           *:ObsidianNewHere*
:ObsidianNewHere
    Create in the current snacks explorer, neo-tree, nvim-tree, oil.nvim, or netrw
    directory. Falls back to notes_subdir only when no explorer is detected; an
    explicitly detected directory outside the Vault is rejected.

                                                        *:ObsidianSwitchVault*
:ObsidianSwitchVault
    Select and switch the active Vault.

                                                            *:ObsidianSwitch*
:ObsidianSwitch
    Fuzzy-find Markdown notes within picker_scope through snacks.nvim.

                                                            *:ObsidianSearch*
:ObsidianSearch [query]
    Search Markdown within picker_scope through snacks.nvim and ripgrep.

                                                       *:ObsidianBacklinks*
:ObsidianBacklinks
    Scan the whole Vault for Wikilinks that resolve to the current note and show them
    in a Snacks Picker. Qualified links, aliases, headings, block IDs, and embeds are
    recognized; ambiguous short links are not guessed. Fenced code, inline code, and
    %% comments are ignored. Confirmation jumps to the reference line without LSP.

                                                              *:ObsidianMove*
:ObsidianMove [target]
    Move the current Markdown note or file-tree selection and update Wikilinks that
    resolve to it. target is a Vault-relative Note ID; .md is optional. A trailing
    slash or existing directory preserves the filename. A missing target prompts.
    A short link stays short when the new basename is unique, becomes Vault-qualified
    when ambiguous, and an originally qualified link stays qualified. Aliases,
    fragments, and explicit .md suffixes are preserved.
    Press Tab in the command line or interactive prompt to complete Vault-relative
    directories. A typed prefix filters candidates. In the interactive completion
    menu, Down/j selects next and Up/h/k selects previous. Candidates end in /.
    Supported LSP clients receive rename and watched-file notifications after success
    so definition and reference indexes switch to the new path.

                                                            *:ObsidianRename*
:ObsidianRename [new-name]
    Rename the current Markdown note or file-tree selection in its existing directory
    and update Wikilinks that resolve to it. Only a filename is accepted; .md is
    optional. A missing name prompts. Use ObsidianMove to change the directory. A
    frontmatter title and the first level-one heading are synchronized when they still
    exactly match the old filename; custom titles are preserved. References use the
    same shortest-unambiguous link policy.

                                                          *:ObsidianTemplate*
:ObsidianTemplate
    Select a recursive template, render it, and insert below the cursor.

                                                       *:ObsidianNewTemplate*
:ObsidianNewTemplate [name]
    Create or open a template without replacing an existing target.

                                                          *:ObsidianPasteFile*
:ObsidianPasteFile [name]
    Paste macOS clipboard files or images into attachments_folder and insert a
    relative Markdown link. Images use `![](path)`, other files use
    `[filename](path)`. Collisions use an incremented name and exclusive
    publication.

                                                             *:ObsidianToday*
:ObsidianToday[!]
    Open or exclusively create today's Daily Note. ! passes
    opts.switch_root=true to after_note_open.

                                                             *:ObsidianSetup*
:ObsidianSetup
    Call setup() with defaults, mainly for tests or use without a plugin manager.

5. WORKFLOWS                                            *miniobsidian-workflows*

WIKILINK                                                   *miniobsidian-wikilink*

Navigation supports [[Note]], [[Folder/Note]], [[Note|Alias]], [[Note#Heading]],
and [[Note#^block-id]]. Duplicate basenames require explicit selection. After
confirmation, a missing target is created relative to the Vault: [[Folder/Note]]
becomes Folder/Note.md, while bare [[Note]] is created at the Vault root rather
than in notes_subdir.

Current-document [[#Heading]] links are not supported. blink completion provides
note targets only, not aliases, headings, or block IDs. Duplicate candidates insert
qualified Vault-relative IDs; previews read the first ten lines.

Heading lookup matches visible heading text case-insensitively and recognizes -1,
-2, and later duplicate suffixes. It is not a complete Obsidian anchor-slug
implementation. Block IDs match only at the end of a line.

CHECKBOX                                                   *miniobsidian-checkbox*

checkbox.toggle() cycles through checkbox_states. Plain -, *, and + list items are
upgraded to the first state. checkbox.clear() restores a checkbox to a plain list
item. Typing - [, * [, or + [ exposes every configured state through blink.

TEMPLATES                                                   *miniobsidian-template*

Variables are case-insensitive: {{date}}, {{time}}, {{title}}, {{filename}},
{{yesterday}}, {{tomorrow}}, and {{date:FORMAT}}. Unknown ordinary variables remain
unchanged and produce warnings.

FORMAT supports YYYY, YY, MMMM, MMM, MM, DD, dddd, ddd, HH, hh, mm, ss, A, a,
and [literal]. Unsupported tokens fail the render.

An explicitly configured daily_date_format uses Lua os.date syntax. An
Obsidian Moment format is applied only when all tokens belong to the supported
subset above.

DAILY NOTES                                               *miniobsidian-daily-note*

The target is dailies_folder/os.date(daily_date_format).md. An existing file opens
without reading its old template. A new file renders daily_template, or uses
daily_default_content when no template is configured. Missing or ambiguous templates
abort creation.

IMAGE PASTE                                                    *miniobsidian-image*

macOS only. Finder images preserve PNG, JPEG, GIF, WEBP, HEIC, HEIF, TIFF, BMP, or
SVG. Screenshots and browser images become PNG/JPG/GIF. Existing names use name-1,
name-2, and so on. A temporary file is published with no-replace semantics.

6. LUA API                                                    *miniobsidian-api*

Core:
>lua
  local core = require("miniobsidian")
  core.setup(opts)                 -- true, or false, errors
  core.default_config()            -- fresh defaults
  core.validate_config(config)     -- string[]
  core.get_all_notes(force)        -- absolute string[]
  core.invalidate_cache()
  core.update_note_cache(path)
  core.get_cache_stamp()
  core.note_stem(path)
  core.in_vault(path)
<

Notes:
>lua
  local note = require("miniobsidian.note")
  note.new_note()                  -- interactive title prompt
  note.new_note("Title", { switch_root = true })
  note.new_note_here()
  note.new_note_in_dir(absolute_dir)
  note.quick_switch()
  note.search()
  note.search("query")
  note.backlinks()
  note.follow_or_create(wikilink_or_parsed)
  note.move("Archive/New Path")
  note.rename("New Filename")
<

Other workflows:
>lua
  require("miniobsidian.vault").pick_and_switch()
  require("miniobsidian.vault").do_switch({
    name = "Personal", path = "/abs/vault",
  })
  require("miniobsidian.daily").open_today()
  require("miniobsidian.daily").resolve_today()
  require("miniobsidian.template").insert()
  require("miniobsidian.template").new_template()
  require("miniobsidian.link").link_at_cursor()
  require("miniobsidian.link").follow_link_or_toggle()
  require("miniobsidian.checkbox").toggle()
  require("miniobsidian.checkbox").clear()
  require("miniobsidian.image").paste_file()
<

No-argument calls use interactive input or defaults. resolve_today() is a
read-only planning API returning plan, nil or nil, error; it neither creates nor
opens a file.

wikilink.*, config_sync.*, path.*, fs.*, image.resolve_for_snacks, and
completion.new are lower-level integration helpers and may change more readily.

7. CALLBACKS AND EVENTS                                  *miniobsidian-callbacks*

after_note_open(path, opts)
    Runs for new_note() (including an existing Note ID), creation after a missing
    Wikilink, and Daily Note workflows. Existing-link navigation, templates, and
    picker workflows do not call it. MiniObsidianNoteOpened fires first;
    opts.switch_root comes from command !.

on_vault_switch(name, path)
    Runs after Vault configuration is committed, the cache is invalidated, and
    MiniObsidianVaultSwitch fires. Initial setup() does not fire this event or
    callback. change_cwd_on_switch also applies only to runtime switches.

User callback failures produce WARN notifications without interrupting plugin flow.

quick_switch() and search() let snacks open files and do not call after_note_open.
Use BufEnter plus core.in_vault(path) for picker-opened notes.

MiniObsidianSetup
    Fires after successful setup. No data.

MiniObsidianVaultSwitch
    Fires after a successful switch. data = { name, path }.

MiniObsidianNoteOpened
    Fires after a direct plugin note open. data = { path, opts }.

MiniObsidianNoteMoved
    Fires after the note and its references are updated.
    data = { operation, old_path, new_path, updated_files, updated_links,
    updated_identity_fields }.

MiniObsidianNoteRenamed
    Fires after a rename and its references are updated.
    data = { operation, old_path, new_path, updated_files, updated_links,
    updated_identity_fields }.

8. HEALTH                                                    *miniobsidian-health*

Run:
>vim
  :checkhealth miniobsidian
<

Checks the Neovim version, snacks.nvim, blink.cmp, ripgrep, osascript,
configuration validity, Vault discovery source, and the active Vault.

Development verification:
>sh
  make ci
<

Full verification requires stylua, selene, and plenary.nvim. Override the
Makefile defaults with NVIM and PLENARY_DIR when needed.
