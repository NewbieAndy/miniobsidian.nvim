1. INTRODUCTION                                      *miniobsidian-introduction*

miniobsidian.nvim provides Vault discovery, note creation, search, Wikilinks,
templates, Daily Notes, checkboxes, and image paste. It is a standalone editor
plugin and has no external CLI or Agent integration.

The plugin does not coordinate concurrent writes made by other applications.
Neovim's native file-change behavior applies. Create operations do use
no-replace semantics, so an existing target is never truncated.

===============================================================================
2. SETUP                                                    *miniobsidian-setup*

>lua
  require("miniobsidian").setup({
    vaults_parent = "",
    default_vault = "",
    auto_discover = true,
    sync_obsidian_config = true,
    notes_subdir = "Notes",
    dailies_folder = "",
    daily_template = "",
    daily_default_content = "",
    templates_folder = "Templates",
    attachments_folder = "Assets",
    daily_date_format = "%Y-%m-%d",
    picker_scope = "notes",
    change_cwd_on_switch = false,
    checkbox_states = { " ", "x" },
    note_id_func = function(title)
      return title:lower():gsub("%s+", "-")
    end,
    on_vault_switch = nil,
    after_note_open = nil,
  })
<

User values take precedence over settings read from .obsidian/app.json and
.obsidian/daily-notes.json.

3. COMMANDS                                              *miniobsidian-commands*

                                                               *:ObsidianNew*
:ObsidianNew[!] [title]
    Create or open a note in notes_subdir.

                                                           *:ObsidianNewHere*
:ObsidianNewHere
    Create a note in the directory selected by a supported file explorer.

                                                        *:ObsidianSwitchVault*
:ObsidianSwitchVault
    Select the active Vault.

                                                            *:ObsidianSwitch*
:ObsidianSwitch
    Open the note picker.

                                                            *:ObsidianSearch*
:ObsidianSearch [query]
    Search Markdown content with snacks.nvim and ripgrep.

                                                          *:ObsidianTemplate*
:ObsidianTemplate
    Select and insert a template.

                                                       *:ObsidianNewTemplate*
:ObsidianNewTemplate [name]
    Create or open a template without replacing an existing file.

                                                          *:ObsidianPasteImg*
:ObsidianPasteImg [name]
    Paste a clipboard image on macOS.

                                                             *:ObsidianToday*
:ObsidianToday[!]
    Open or exclusively create today's Daily Note.

                                                             *:ObsidianSetup*
:ObsidianSetup
    Initialize the plugin with defaults.

4. API                                                        *miniobsidian-api*

>lua
  require("miniobsidian.note").new_note(title?, opts?)
  require("miniobsidian.note").new_note_here()
  require("miniobsidian.note").quick_switch()
  require("miniobsidian.note").search(query?)
  require("miniobsidian.daily").open_today(opts?)
  require("miniobsidian.template").insert()
  require("miniobsidian.template").new_template(name?)
  require("miniobsidian.vault").pick_and_switch()
  require("miniobsidian.link").follow_link_or_toggle()
  require("miniobsidian.checkbox").toggle()
<

===============================================================================
5. EVENTS                                                  *miniobsidian-events*

MiniObsidianSetup
    Fired after setup finishes.

MiniObsidianVaultSwitch
    Fired after switching Vault. Data: { name, path }.

MiniObsidianNoteOpened
    Fired after a note is opened. Data: { path, opts }.
