1. 简介                                         *miniobsidian-zh-introduction*

miniobsidian.nvim 是独立的轻量 Neovim 笔记插件，提供 Vault 发现、笔记创建、
搜索、Wikilink、模板、Daily Note、Checkbox 和图片粘贴。

插件不集成外部 CLI 或 Agent，也不协调其他应用的并发写入。外部文件变化沿用
Neovim 原生行为。插件自身的新建操作使用 no-replace 语义，不会截断已有文件。

2. 配置                                                *miniobsidian-zh-setup*

>lua
  require("miniobsidian").setup({
    vaults_parent = "",
    default_vault = "",
    auto_discover = true,
    sync_obsidian_config = true,
    notes_subdir = "Notes",
    dailies_folder = "",
    daily_template = "",
    daily_default_content = "",
    templates_folder = "Templates",
    attachments_folder = "Assets",
    daily_date_format = "%Y-%m-%d",
    picker_scope = "notes",
    change_cwd_on_switch = false,
    checkbox_states = { " ", "x" },
    on_vault_switch = nil,
    after_note_open = nil,
  })
<

用户显式配置优先于 .obsidian/app.json 和 .obsidian/daily-notes.json。

3. 命令                                             *miniobsidian-zh-commands*

:ObsidianNew[!] [标题]
    在 notes_subdir 创建或打开笔记。

:ObsidianNewHere
    在支持的文件树当前目录创建笔记。

:ObsidianSwitchVault
    选择活跃 Vault。

:ObsidianSwitch
    打开笔记选择器。

:ObsidianSearch [关键词]
    使用 snacks.nvim 和 ripgrep 搜索 Markdown 内容。

:ObsidianTemplate
    选择并插入模板。

:ObsidianNewTemplate [名称]
    创建或打开模板，不覆盖已有文件。

:ObsidianPasteImg [名称]
    在 macOS 粘贴剪贴板图片。

:ObsidianToday[!]
    打开或安全创建今日笔记。

:ObsidianSetup
    使用默认配置初始化插件。

===============================================================================
5. 事件                                               *miniobsidian-zh-events*

MiniObsidianSetup
    setup 完成后触发。

MiniObsidianVaultSwitch
    切换 Vault 后触发。data = { name, path }。

MiniObsidianNoteOpened
    打开笔记后触发。data = { path, opts }。
