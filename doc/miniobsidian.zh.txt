1. 简介                                         *miniobsidian-zh-introduction*

miniobsidian.nvim 是独立的轻量 Neovim 笔记插件，提供 Vault 发现和切换、
笔记创建与搜索、Wikilink、模板、Daily Note、Checkbox 和 macOS 图片粘贴。

插件不集成外部 CLI 或 Agent，也不协调其他应用的并发写入。外部文件变化沿用
Neovim 原生行为。插件自身限制所有目标位于当前 Vault 内，并以 no-replace
语义创建笔记、模板、Daily Note 和图片。

2. 要求与安装                                  *miniobsidian-zh-installation*

必需：Neovim >= 0.10.4。

可选：

  snacks.nvim    快速切换和全文搜索
  blink.cmp      Wikilink 与 Checkbox 补全
  ripgrep        全文搜索
  osascript      macOS 图片粘贴

Vault 和模板选择会回退到 vim.ui.select。缺少 snacks.nvim 时只有
ObsidianSwitch、ObsidianSearch 不可用；缺少 ripgrep 时只有全文搜索不可用。

lazy.nvim 插件配置：
>lua
  {
    "andy-neoaira/miniobsidian.nvim",
    ft = "markdown",
    cmd = {
      "ObsidianNew", "ObsidianNewHere", "ObsidianSwitchVault",
      "ObsidianSwitch", "ObsidianSearch", "ObsidianTemplate",
      "ObsidianNewTemplate", "ObsidianPasteImg", "ObsidianToday",
      "ObsidianSetup",
    },
    config = function()
      require("miniobsidian").setup()
    end,
  }
<

最小配置：
>lua
  require("miniobsidian").setup()
<

默认从 Obsidian 官方 obsidian.json 自动发现 Vault，并忽略不存在或不含
.obsidian/ 的条目。手动发现只扫描 vaults_parent 的直属子目录，且目录必须
包含 .obsidian/：
>lua
  require("miniobsidian").setup({
    vaults_parent = "~/Documents/Obsidian",
    default_vault = "Personal",
    auto_discover = false,
  })
<

3. 配置                                               *miniobsidian-zh-config*

默认值与含义：

  vaults_parent = ""
      Vault 父目录；支持 ~ 和环境变量展开。为空时使用自动发现。

  default_vault = ""
      初始 Vault 名；为空或找不到时使用发现结果首项。自动发现时 Obsidian
      标记为打开的 Vault 优先。

  auto_discover = true
      vaults_parent 为空时读取 Obsidian 官方配置。

  sync_obsidian_config = true
      只读当前 Vault 的 .obsidian 配置，不写入官方配置。

  notes_subdir = "Notes"
      新笔记目录，Vault 相对路径；空字符串表示 Vault 根目录。

  dailies_folder = ""
      Daily Note 目录，Vault 相对路径。

  daily_template = ""
      Daily Note 模板的 Vault 相对 Note ID，可省略 .md。

  daily_default_content = ""
      没有模板时写入新 Daily Note 的内容。

  templates_folder = "Templates"
      模板目录，Vault 相对路径。

  attachments_folder = "Assets"
      图片附件目录，Vault 相对路径。

  daily_date_format = "%Y-%m-%d"
      Lua os.date 格式，用于 Daily 文件名和新笔记 frontmatter 日期。

  picker_scope = "notes"
      "notes" 只搜索 notes_subdir；"vault" 搜索整个 Vault。

  change_cwd_on_switch = false
      Vault 切换成功后是否对当前 tab 执行 :tcd。

  checkbox_states = { " ", "x" }
      Checkbox 循环及补全顺序。

  note_id_func = <内置 CJK slug 函数>
      将标题转换为不含 .md 的新笔记文件名。默认保留 ASCII 字母数字和中日韩
      文字，删除其他标点，连续空白替换为 -，ASCII 转小写。

  on_vault_switch = nil
      function(name, path)，Vault 成功切换后调用。

  after_note_open = nil
      function(path, opts)，插件直接打开笔记后调用。

vault_path 是运行时内部字段，不应手动配置。

目录配置拒绝父目录穿越、绝对路径、隐藏目录、NUL、Windows ADS、保留设备名
和以点或空格结尾的路径段。daily_template 会在解析 Daily Note 时执行相同的
Vault 边界检查。

配置同步：

  .obsidian/app.json
      newFileLocation="root" -> notes_subdir=""
      newFileLocation="folder" 加 newFileFolderPath -> notes_subdir

  .obsidian/daily-notes.json
      folder   -> dailies_folder
      支持的 Moment format -> Lua daily_date_format
      template -> daily_template

优先级：用户显式配置 > 当前 Vault 官方配置 > 插件默认值。切换 Vault 时同步
字段会完整重建；目录字段校验成功后才提交，非法目录会保留原 Vault。不支持的
Moment token 不会同步；daily_template 缺失、歧义或路径不安全时，会在后续
Daily Note 创建前中止操作。

setup(opts) 成功返回 true。配置非法、没有有效 Vault 或已校验的同步目录非法时
返回 false, errors，并且不会触发 MiniObsidianSetup。
再次调用 setup() 会先重置运行时配置和缓存；它与运行中的
ObsidianSwitchVault 不同，失败时不保证保留旧状态。

blink.cmp provider：
>lua
  opts.sources.providers.miniobsidian = {
    name = "MiniObsidian",
    module = "miniobsidian.completion",
    score_offset = 50,
  }
  table.insert(opts.sources.default, "miniobsidian")
<

4. 命令                                            *miniobsidian-zh-commands*

                                         *miniobsidian-zh-command-new*
:ObsidianNew[!] [标题]
    在 notes_subdir 创建或打开笔记。标题省略时提示输入。! 向
    after_note_open 传入 opts.switch_root=true。

                                    *miniobsidian-zh-command-new-here*
:ObsidianNewHere
    在文件树当前目录创建笔记。支持 snacks explorer、neo-tree、nvim-tree、
    oil.nvim 和 netrw。未检测到文件树时回退到 notes_subdir；检测到 Vault 外
    目录时中止。

                                *miniobsidian-zh-command-switch-vault*
:ObsidianSwitchVault
    选择并切换活跃 Vault。

                                      *miniobsidian-zh-command-switch*
:ObsidianSwitch
    在 picker_scope 范围内使用 snacks.nvim 模糊查找 Markdown 笔记。

                                      *miniobsidian-zh-command-search*
:ObsidianSearch [关键词]
    在 picker_scope 范围内使用 snacks.nvim 和 ripgrep 全文搜索 Markdown。

                                    *miniobsidian-zh-command-template*
:ObsidianTemplate
    递归选择模板，渲染后插入当前光标下一行。

                                *miniobsidian-zh-command-new-template*
:ObsidianNewTemplate [名称]
    创建或打开模板，不覆盖已有目标。

                                   *miniobsidian-zh-command-paste-img*
:ObsidianPasteImg [名称]
    在 macOS 粘贴剪贴板图片，保存到 attachments_folder 并插入相对链接。
    同名文件自动递增，并以排他方式发布。

                                       *miniobsidian-zh-command-today*
:ObsidianToday[!]
    打开或安全创建今日笔记。! 向 after_note_open 传入
    opts.switch_root=true。

                                       *miniobsidian-zh-command-setup*
:ObsidianSetup
    使用默认值调用 setup()，通常只用于测试或无插件管理器环境。

5. 工作流                                         *miniobsidian-zh-workflows*

WIKILINK                                             *miniobsidian-zh-wikilink*

导航支持 [[Note]]、[[Folder/Note]]、[[Note|Alias]]、[[Note#Heading]] 和
[[Note#^block-id]]。同 basename 多篇笔记时要求选择。缺失目标确认后按 Vault
相对位置创建：[[Folder/Note]] 创建 Folder/Note.md，裸 [[Note]] 创建到 Vault
根目录，而不是 notes_subdir。

当前不支持当前文档内部链接 [[#Heading]]。blink 补全只提供笔记目标，不补全
alias、heading 或 block ID。同名候选插入 Vault 相对限定路径，预览读取前 10 行。

Heading 按可见标题文本做大小写不敏感匹配，并识别重复标题的 -1、-2 等后缀；
这不是完整的 Obsidian anchor slug 实现。Block ID 只匹配行末的 ^block-id。

CHECKBOX                                             *miniobsidian-zh-checkbox*

checkbox.toggle() 按 checkbox_states 循环；普通 -、*、+ 列表项会升级为第一个
状态。checkbox.clear() 将 Checkbox 恢复为普通列表项。输入 - [、* [ 或 + [
时，blink source 提供所有配置状态。

模板                                                   *miniobsidian-zh-template*

变量大小写不敏感：{{date}}、{{time}}、{{title}}、{{filename}}、
{{yesterday}}、{{tomorrow}} 和 {{date:FORMAT}}。未知普通变量保留并警告。

FORMAT 支持 YYYY、YY、MMMM、MMM、MM、DD、dddd、ddd、HH、hh、mm、ss、
A、a 和 [literal]。不支持的 token 会使渲染失败。

显式配置的 daily_date_format 使用 Lua os.date 语法；从 Obsidian 同步的 Moment
格式只有全部 token 属于上述子集时才会应用。

DAILY NOTE                                        *miniobsidian-zh-daily-note*

目标为 dailies_folder/os.date(daily_date_format).md。已有文件直接打开，不读取
旧模板；新文件优先渲染 daily_template，没有模板则写 daily_default_content。
模板缺失或存在 basename 歧义时中止创建。

图片                                                   *miniobsidian-zh-image*

仅 macOS 支持。Finder 图片保留 PNG、JPEG、GIF、WEBP、HEIC、HEIF、TIFF、
BMP 或 SVG；截图和浏览器图片输出 PNG/JPG/GIF。若名称已被任一支持格式占用，
自动选择 name-1、name-2。临时文件以 no-replace 方式发布，已有图片不会替换。

6. LUA API                                              *miniobsidian-zh-api*

核心：
>lua
  local core = require("miniobsidian")
  core.setup(opts)                 -- true，或 false, errors
  core.default_config()            -- 新的默认配置表
  core.validate_config(config)     -- string[]
  core.get_all_notes(force)        -- string[] 绝对路径
  core.invalidate_cache()
  core.update_note_cache(path)
  core.get_cache_stamp()
  core.note_stem(path)
  core.in_vault(path)
<

笔记：
>lua
  local note = require("miniobsidian.note")
  note.new_note()                  -- 交互输入标题
  note.new_note("标题", { switch_root = true })
  note.new_note_here()
  note.new_note_in_dir(absolute_dir)
  note.quick_switch()
  note.search()
  note.search("关键词")
  note.follow_or_create(wikilink_or_parsed)
<

其他工作流：
>lua
  require("miniobsidian.vault").pick_and_switch()
  require("miniobsidian.vault").do_switch({
    name = "Personal", path = "/abs/vault",
  })
  require("miniobsidian.daily").open_today()
  require("miniobsidian.daily").resolve_today()
  require("miniobsidian.template").insert()
  require("miniobsidian.template").new_template()
  require("miniobsidian.link").link_at_cursor()
  require("miniobsidian.link").follow_link_or_toggle()
  require("miniobsidian.checkbox").toggle()
  require("miniobsidian.checkbox").clear()
  require("miniobsidian.image").paste_img()
<

上述无参调用使用交互输入或默认值。resolve_today() 是只读规划接口，返回
plan, nil 或 nil, error，不创建也不打开文件。

wikilink.*、config_sync.*、path.*、fs.*、image.resolve_for_snacks 和
completion.new 主要是底层集成接口，稳定性低于上述用户工作流 API。

7. 回调与事件                                    *miniobsidian-zh-callbacks*

after_note_open(path, opts)
    由 new_note()（包括同 ID 已有笔记）、跟随缺失链接后的创建和 Daily Note
    调用。已有链接跳转、模板和 picker 流程不调用。事件
    MiniObsidianNoteOpened 先触发。opts.switch_root 来自命令的 !。

on_vault_switch(name, path)
    Vault 配置提交、缓存失效和 MiniObsidianVaultSwitch 触发后调用。初始
    setup() 不触发该事件或回调；change_cwd_on_switch 也只作用于运行时切换。

用户回调异常会产生 WARN 通知，但不会中断插件流程。

quick_switch() 和 search() 由 snacks 打开文件，不调用 after_note_open。需要处理
picker 打开的文件时，应注册 BufEnter 并用 core.in_vault(path) 过滤。

MiniObsidianSetup
    setup 成功后触发，无 data。

MiniObsidianVaultSwitch
    切换成功后触发。data = { name, path }。

MiniObsidianNoteOpened
    插件直接打开笔记后触发。data = { path, opts }。

8. 健康检查                                        *miniobsidian-zh-health*

执行：
>vim
  :checkhealth miniobsidian
<

检查 Neovim 版本、snacks.nvim、blink.cmp、ripgrep、osascript、配置合法性、
Vault 发现来源和当前活跃 Vault。

开发验证：
>sh
  make ci
<

完整校验需要 stylua、selene 和 plenary.nvim；必要时可通过 NVIM 与
PLENARY_DIR 覆盖 Makefile 默认路径。
